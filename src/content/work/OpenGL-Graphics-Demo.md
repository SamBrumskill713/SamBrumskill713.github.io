### What I did?
This coursework was my first introduction to OpenGL in 3D. We were tasked with creating a 3D scene that showcases different graphics techniques. My scene consisted of a space marine wandering through a swampy landscape before transitioning to a destroyed version of the landscape with a monolithic obelisk serving as the inciting incident.

In this project I implemented:
- Deferred Rendering
- Real-Time Shadows
- Cube-mapped reflections
- Skybox

### How I expanded on this base?
In this project, I added animation to the scene with the soldier walking around the swampy landscape. I also implemented deferred and animated shadows for the soldier and the other objects in the scene.

### What did I learn?

In this coursework, I learned about the graphics pipeline and how the different shaders work to produce graphics using the graphics card. I also learned about several different graphical techniques such as real-time lighting, scene graphs, index buffering, deferred rendering, etc.
